# Contribuindo para o falcon-master

Obrigado por considerar contribuir! Abaixo estão algumas diretrizes para facilitar sua contribuição.

## Como contribuir
1. Fork este repositório para sua conta e clone localmente.
2. Crie uma branch com um nome descritivo: `feature/nova-coisa` ou `fix/issue-123`.
3. Faça commits pequenos e com mensagens claras.
4. Garanta que os testes existentes passam e adicione testes para novas funcionalidades.
5. Abra um Pull Request contra a branch `main` do repositório original.

## Padrões de código
- Utilize 4 espaços para indentação (PEP 8).
- Execute `flake8` antes de abrir PRs.
- Escreva testes para casos significativos e automatizáveis.

## Issues
- Antes de implementar uma alteração maior, abra uma issue para discutir a proposta.
- Use os templates de issue disponíveis ao abrir novos reports.

## Testes
- Rode `pytest` para executar a suíte de testes.
- Adicione testes unitários para novas funcionalidades ou correções.

## Estilo de commits
- Mensagens no estilo: `tipo: descrição curta` (ex.: `feat: adicionar suporte a X`, `fix: corrigir Y`).

## Revisão de PR
- Um mantenedor revisará seu PR. Pode haver pedidos de mudanças — responda a eles e atualize sua branch.

## Código de conduta
Ao contribuir, você concorda em seguir o Código de Conduta do projeto.
