# Código de Conduta

Este projeto adere ao Código de Conduta do Contributor Covenant. Ao participar deste projeto, espera-se que você siga as diretrizes descritas abaixo.

## Padrões
- Seja respeitoso e cortês com os demais contribuidores.
- Evite linguagem ou comportamentos discriminatórios, abusivos ou de assédio.

## Aplicação
Se você testemunhar ou sofrer um comportamento inapropriado, por favor reporte aos mantenedores do projeto.

## Consequências
Comportamentos que violem este código de conduta podem resultar em ação corretiva, incluindo exclusão de comentários ou banimento do projeto.
